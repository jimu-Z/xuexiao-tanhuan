# 用户操作手册

## 首次配置

1. 管理员登录后先建立学院，核对角色和数据权限。
2. 在教师管理中录入或导入教师，再按学院配置年级、班级和负责人。
3. 从学生管理页面下载当前导入模板，按模板填写。先用少量样本验证字段、班级和负责人，再导入其余数据，等待导入结果后检查失败行。
4. 按业务要求准备学生标签、谈话分类和谈话模板。
5. 分别用校级、院级和教师账号登录，核对可见学生及谈话范围。

## 记录一次谈话

1. 在谈话记录功能中新增谈话，选择学生、谈话时间、类型和参与人员。
2. 填写谈话内容及处理记录，按实际情况添加附件，然后保存。
3. 在谈话列表中查回这条记录，核对学生、参与人员和附件。需要归档时使用文书导出功能。
4. 补录存量记录时使用历史谈话导入，先核对预览中的学生、班级、谈话人和异常行。

## 账号与数据范围

| 角色 | 用途 |
| --- | --- |
| `admin` | 系统维护、账号授权和全校管理 |
| `school_admin` | 校级业务管理 |
| `college_admin` | 所属学院业务管理 |
| `talk_teacher` | 在配置的数据权限范围内处理学生及谈话 |

实际可见菜单和数据由角色授权、学院归属和管理关系决定。向校外分享文书或报表前，按学校规定处理身份信息、谈话内容和附件。
