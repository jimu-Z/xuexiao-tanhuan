# 学生谈心谈话管理系统

面向高校的学生谈心谈话管理系统，支持谈话记录、学生与教师管理、数据导入导出和权限审计。

## 主要功能

- 管理学院、年级、班级、学生、教师和班级负责人，支持按模板批量导入。
- 登记个别或集体谈话，记录多人参与和附件，支持历史谈话导入、记录查询和 Word 文书导出。
- 按账号角色和数据范围授权，提供操作日志、统计和工作台。

## 源码结构

| 目录 | 用途 |
| --- | --- |
| `RuoYi-Vue-master/` | 基于 RuoYi-Vue 的 Java 后端和管理端 |
| `RuoYi-Vue-master/ruoyi-ui/` | Vue 2 管理端 |
| `Student-UI/` | 保留的学生端源码。当前管理端的标准部署无需启动学生端 |
| `database/` | 空库结构、基础种子数据和管理员初始化脚本 |
| `docs/` | 系统介绍、安装部署和使用说明 |

## 开始使用

功能、角色权限和业务流程见[详细系统介绍](docs/SYSTEM-OVERVIEW.md)。

1. 按[数据库说明](database/README.md)初始化空库并创建管理员。
2. 按[安装部署说明](docs/DEPLOYMENT.md)启动后端、构建管理端并配置反向代理。
3. 按[操作手册](docs/USER-GUIDE.md)建立组织、导入数据并验证权限。
